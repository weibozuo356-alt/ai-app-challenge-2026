# BugMentor 现场演示指南（6 分钟）

## 一句话价值主张

BugMentor 是一个不会直接告诉学生答案、而是通过五级追问、修改验证和学习复盘培养 Python 调试能力的专业课助教。

## 演示前 10 分钟

1. 打开 https://bugmentor-api.onrender.com 确认返回“BugMentor 后端运行成功”。
2. 打开 https://ai-app-challenge-2026.vercel.app/，载入 IndexError 示例。
3. 确认 DeepSeek 仍能返回一级提示，随后点击重置，保持首页干净。
4. 浏览器缩放设为 100%，关闭无关标签页和通知。
5. 将本指南、技术文档 PDF 和备用录屏放在本地可快速打开的位置。

## 6 分钟时间轴

### 0:00—0:35 痛点与定位

“初学者面对报错时，通常只会把完整答案复制走，却没有学会如何观察报错、定位代码和验证猜想。BugMentor 把一次报错转化成可追踪的学习过程。”

展示首页和“专业课助教版”标识，强调目标用户是 Python 初学者。

### 0:35—2:35 五级引导

载入 IndexError 示例并开始调试：

```python
numbers = [10, 20, 30]
print(numbers[3])
```

- 展示第一级只让学生观察报错，不直接公布答案。
- 不填写“我的判断”，证明下一等级保持锁定。
- 输入：“列表有 3 个元素，但代码访问了下标 3，我怀疑超出范围。”
- 提交判断并展示反馈，再进入第二级。
- 快速说明第三、四级会围绕当前代码解释索引规则，第五级才给完整答案。

### 2:35—3:40 修改与验证闭环

把 `numbers[3]` 改为 `numbers[2]`，点击重新验证：

- 展示绿色“验证通过”。
- 说明当前是可解释的静态规则模拟，没有在服务器执行不可信代码。
- 再临时改回 `numbers[3]`，展示旧成功状态失效、复盘重新锁定；然后恢复正确代码并再次验证。

### 3:40—4:45 学习复盘与个性化建议

- 展示自动填充的错误类型、知识点、根本原因和预防措施。
- 保存复盘，展示历史记录和 JSON 导出。
- 展示高频错误统计、三阶段复习建议和迁移练习。
- 强调历史统计在浏览器本地完成，不发送给 AI 后端。

### 4:45—5:30 工程与合规

展示技术文档中的架构：React 前端 → FastAPI 网关 → DeepSeek；localStorage 管理学习状态。说明：

- 35 项前端测试 + 12 项后端测试。
- GitHub Actions 自动执行测试、Lint、构建和依赖检查。
- CORS 白名单、安全响应头、输入长度限制、密钥只在服务端。
- Vercel 与 Render 已在线部署。

### 5:30—6:00 总结

“BugMentor 的价值不是替学生修一个 Bug，而是把观察、假设、验证和复盘固化成可重复的学习方法。后续可以扩展更多课程错误类型、教师用例库和学习分析。”

## 现场挑战案例

### 案例 A：TypeError

```python
age = 18
print("年龄：" + age)
```

可接受修复：`str(age)`、f-string 或 `print("年龄：", age)`。

### 案例 B：SyntaxError

```python
score = 85
if score >= 60
    print("及格")
```

可接受修复：为 `if` 条件行补上冒号，不能通过删除原语句规避验证。

## 离线兜底

1. 若 Render 冷启动：先讲产品定位，同时后台打开后端根地址等待唤醒。
2. 若 DeepSeek 暂时不可用：使用已录制的核心流程片段，并现场展示本地验证器、复盘和测试报告。
3. 若现场网络完全不可用：运行本地前后端；仍不可用时展示正式 PDF、关键截图和备用视频。
4. 不临时修改生产代码或泄露 `.env`、API Key、手机号、邮箱等信息。
