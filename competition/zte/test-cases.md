# BugMentor 正式测试用例

## 1. 测试环境

- 在线前端：https://ai-app-challenge-2026.vercel.app/
- 在线后端：https://bugmentor-api.onrender.com
- 桌面浏览器：Chrome / Edge 当前稳定版
- 移动端：浏览器响应式模式或真实手机浏览器
- 自动化：Node.js 22、Python 3.13

## 2. 手工验收用例

| ID | 类型 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|---|
| TC-01 | 正常 | 打开首页 | 载入 IndexError 示例并开始调试 | 返回第1级提示，不直接给出具体下标答案 |
| TC-02 | 正常 | 已获得提示 | 不填写“我的判断” | 提交判断和下一级按钮保持禁用 |
| TC-03 | 正常 | 当前等级已开始 | 填写非空判断并提交 | 显示 AI 反馈；本级反馈成功后才解锁下一等级 |
| TC-04 | 正常 | 已完成第1级反馈 | 获取第2级提示 | 进入第2级；新等级的下一级按钮重新锁定 |
| TC-05 | 边界 | 处于第1—4级 | 尝试查看完整答案 | 第5级之前不能直接显示完整修改代码 |
| TC-06 | 正常 | IndexError 原代码为 `numbers[3]` | 修改为 `numbers[2]` 后验证 | 显示验证通过并解锁复盘 |
| TC-07 | 正常 | IndexError 原代码为 `numbers[3]` | 修改为 `numbers[-1]` 后验证 | 显示验证通过并解锁复盘 |
| TC-08 | 异常 | IndexError 已开始 | 不修改或只改空格/注释后验证 | 验证失败，复盘保持锁定 |
| TC-09 | 异常 | IndexError 已开始 | 删除列表访问语句后验证 | 返回无法判断，不误判为修复成功 |
| TC-10 | 正常 | TypeError 字符串与整数拼接示例 | 使用 `str()`、f-string 或逗号输出后验证 | 验证通过并解锁复盘 |
| TC-11 | 正常 | SyntaxError 缺少冒号示例 | 为原语句补上冒号后验证 | 验证通过并解锁复盘 |
| TC-12 | 异常 | SyntaxError 缺少冒号示例 | 删除原条件语句后验证 | 返回无法判断，不误判成功 |
| TC-13 | 状态 | 已验证成功 | 再次修改代码 | 旧成功状态立即失效，复盘重新锁定 |
| TC-14 | 状态 | 已进入第3级并获得反馈 | 刷新页面 | 恢复代码、提示等级、反馈状态和验证状态 |
| TC-15 | 状态 | 已保存一条复盘 | 刷新、删除单条记录、清空全部 | 记录正确恢复；删除和清空均生效 |
| TC-16 | 异常 | 后端停止或不可访问 | 发起调试请求 | 页面给出可理解的连接失败提示，不崩溃 |
| TC-17 | 异常 | DeepSeek 余额不足或服务异常 | 发起调试请求 | 后端返回安全错误；页面提示稍后重试，不泄露密钥 |
| TC-18 | 边界 | 调试表单为空 | 点击开始调试 | 前端/后端拒绝空代码，不进入错误流程 |
| TC-19 | 安全 | 使用非白名单网页来源 | 跨域请求后端 | CORS 不允许未知来源 |
| TC-20 | 响应式 | 将窗口缩至手机宽度 | 完成提交、判断、验证和复盘 | 布局垂直排列，主要按钮可见且可操作 |
| TC-21 | 知识依据 | 进入支持错误的第3级提示 | 查看课程知识依据卡 | 显示规则、核验方法和 Python 官方文档链接，不包含当前题完整答案 |
| TC-22 | 个性化 | 已保存多条不同错误类型记录 | 查看个性化复习建议 | 正确统计高频错误并生成三阶段复习步骤 |
| TC-23 | 迁移学习 | 已生成支持类型的复习建议 | 点击“载入迁移练习” | 经确认后载入一条新的同知识点案例，并重置旧调试状态 |
| TC-24 | 数据导出 | 至少保存一条学习记录 | 点击“导出 JSON” | 下载包含版本、导出时间、记录数量和记录数组的 JSON 文件 |
| TC-25 | 隐私 | 查看复习建议并导出记录 | 检查网络请求 | 复习统计和导出不向后端发送学习历史 |

## 3. 自动化测试对应

### 前端 35 项

覆盖：

- 会话保存、恢复、损坏数据和旧版本数据降级。
- 每级反馈解锁与第五级答案保护。
- IndexError 合法正索引、负索引、未修改、越界和删除访问。
- TypeError 的 `str()`、f-string、逗号输出、仍直接拼接和删除语句。
- SyntaxError 补冒号、仍缺冒号、删除语句和非目标语法错误。
- 演示案例字段完整与 ID 唯一。
- 知识依据匹配、官方来源链接和大小写兼容。
- 高频错误复习计划、迁移练习推荐和 JSON 导出结构。

运行方式：

```bash
cd frontend
npm test
```

### 后端 12 项

覆盖：

- 根接口、健康检查、正常 AI 提示和学生判断转发。
- AI 服务异常的安全响应。
- 空代码、非法提示等级、超长学生回答。
- 安全响应头、请求 ID、允许和拒绝的 CORS 来源。

运行方式：

```bash
cd backend
.venv/Scripts/python.exe -m unittest test_main -v
```
