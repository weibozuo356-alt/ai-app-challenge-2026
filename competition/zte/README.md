# BugMentor 中兴赛道提交包

本目录对应中兴赛道“专业课助教智能体”命题，记录可运行产品、技术实现、测试证据、合规边界和演示材料。公开仓库不披露手机号、邮箱和学号，联系方式随官方报名表单独提交。

## 材料索引

1. [技术文档](technical-document.md)：架构、模块、核心流程、接口、部署与配置。
2. [测试用例](test-cases.md)：正常、异常和边界场景的正式验收用例。
3. [合规说明](compliance-statement.md)：数据、隐私、模型、开源与安全边界。
4. [演示视频脚本](demo-video-script.md)：3—5 分钟录屏结构和台词。
5. [提交检查表](submission-checklist.md)：报名、材料、产品和答辩检查。
6. [现场演示指南](live-demo-guide.md)：6 分钟演示节奏、挑战案例和离线兜底。
7. [答辩问答题库](defense-qa.md)：准确性、AI 幻觉、隐私、工程边界与教学价值。
8. [发布验收报告](final-package/acceptance-report.md)：线上接口、CI、自动化与视觉证据。
