# BugMentor 3—5 分钟演示视频脚本

建议时长：4 分 40 秒。录制前先访问后端健康检查唤醒 Render，并清空浏览器中无关的历史记录和标签页。

## 0:00—0:25 作品与痛点

画面：BugMentor 首页和标题。

讲解：

> 大家好，我们的作品是 BugMentor，一名不会直接告诉学生答案的 Python 调试教练。很多初学者遇到报错后会让 AI 直接改代码，问题虽然暂时消失，却没有形成独立调试能力。BugMentor 通过分级追问，让学生自己观察、判断、修改和复盘。

## 0:25—0:50 架构与核心闭环

画面：技术文档中的架构图或一页简洁架构幻灯片。

讲解：

> 系统采用 React 前端、FastAPI 后端和 DeepSeek 模型。AI 负责分级提示和判断反馈，前端规则引擎负责典型错误的修改验证，浏览器本地保存调试进度和学习记录。核心流程是“追问、纠错、再讲解、修改验证、学习复盘”。

## 0:50—2:40 IndexError 完整演示

画面与操作：

1. 点击“IndexError：列表索引越界”并载入案例。
2. 开始调试，展示第1级提示没有直接说出正确下标。
3. 不填写判断，展示下一级按钮不能使用。
4. 填写：“列表有三个元素，我怀疑访问的下标超出范围。”
5. 提交判断，展示 AI 反馈和下一级解锁。
6. 获取第2级提示，说明进入新等级后必须再次思考；快速完成第2级判断并进入第3级。
7. 展示第3级出现的课程知识依据卡、核验方法和 Python 官方文档链接。
8. 直接跳到修改演示：将 `numbers[3]` 改为 `numbers[2]`。
9. 点击重新验证，展示绿色通过状态和复盘解锁。

讲解要点：

> 第1至第4级只提供逐步线索，第5级才允许完整答案。学生必须先提交自己的判断并获得反馈，不能连续点击跳级。修改后的代码会由确定性规则检查；验证成功才进入复盘，代码再次改变时旧结论会立即失效。

## 2:40—3:30 学习复盘、复习计划与迁移练习

画面：填写并保存学习记录，随后展示复习建议和迁移练习卡片。

建议填写：

- 错误类型：IndexError
- 涉及知识点：Python 列表索引从 0 开始
- 我的错误原因：把三个元素误认为可以使用下标 3 访问最后一个元素
- 下次如何避免：访问列表前先确认长度，最后一个合法正索引是长度减 1

讲解：

> 调试不是以代码能跑为结束。学生需要用自己的话记录错误类型、知识点、根本原因和预防方法。系统根据本地历史中的高频错误生成三阶段复习建议，并推荐一道新的同知识点迁移练习；记录也可以导出为结构化 JSON。所有统计都在浏览器内完成，不上传学习历史。

## 3:30—4:00 多场景与工程质量

画面：快速切换 TypeError、SyntaxError 示例；展示 GitHub Actions 或测试终端截图。

讲解：

> 当前产品还提供字符串与整数拼接的 TypeError、复合语句缺冒号的 SyntaxError 演示和验证。第三级后会展示可核验的课程知识依据；保存复盘后，系统会按历史高频错误推荐复习步骤和迁移练习。项目有 35 项前端测试、12 项后端测试，并通过 GitHub Actions 自动检查测试、代码规范、生产构建和依赖。

## 4:00—4:25 安全、限制与可用性

画面：在线地址、健康检查、隐私或安全文档。

讲解：

> 用户代码只在请求提示时发送给后端和 DeepSeek，服务端日志不记录代码或密钥。当前版本不会真实执行用户代码，规则无法确认时会诚实提示“暂时无法判断”。前端部署在 Vercel，后端部署在 Render，评委可以直接在线体验。

## 4:25—4:40 结束语

画面：返回产品首页。

讲解：

> BugMentor 的目标不是替学生修好一次代码，而是让学生逐步学会自己修复下一次错误。谢谢各位老师。

## 录制验收

- 时长控制在 3—5 分钟。
- 画面中不出现 DeepSeek 密钥、个人聊天、无关标签页或浏览器收藏。
- 至少完整展示一次“提交—判断—反馈—修改—验证—复盘”。
- 展示一次课程知识依据、复习建议和迁移练习推荐。
- 展示真实在线地址，不使用只能在本机访问的 `localhost`。
- 字号和缩放确保评委能看清代码、按钮和反馈。
- 如果 DeepSeek 暂时不可用，先恢复额度再录制；不要剪辑伪造 AI 成功结果。
