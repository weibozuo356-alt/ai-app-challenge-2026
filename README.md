# BugMentor

不会直接告诉你答案的 AI Debug 教练。

## 项目背景

很多编程初学者遇到报错后，会直接让 AI 给出修改后的代码。
虽然问题暂时解决了，但用户并没有真正理解错误原因，
下一次遇到类似问题时仍然无法独立解决。

## 目标用户

正在学习 Python、能够编写简单代码，
但缺乏独立 Debug 能力的大学生和编程初学者。

## 核心功能

1. 用户提交代码、报错信息和预期结果
2. AI 分析错误类型，但不直接公布答案
3. 通过逐级提示引导用户定位问题
4. 用户修改代码后重新提交
5. 修复成功后生成错误复盘和知识薄弱点记录

## 产品原则

AI 的目标不是替用户修好代码，
而是帮助用户学会自己修复代码。
