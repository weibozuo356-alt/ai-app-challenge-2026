## 二、从单案例测试到多类型测试

昨天主要使用列表索引越界测试 AI 分级提示：

```python
numbers = [10, 20, 30]
print(numbers[3])
```

今天继续检查第 4 级提示，并增加三类测试：

1. `SyntaxError`：例如 `for` 语句末尾缺少冒号。
2. `TypeError`：例如字符串与整数直接相加。
3. 逻辑错误：程序不报错，但计算平均值时使用了错误的除数。

测试结果表明，BugMentor 不只是记住了一个列表越界案例，而是能够根据代码、报错和预期结果分析不同问题。

我进一步理解了：

> 功能测试不能只证明一个示例成功，还要选择不同类型和不同边界的案例，检查产品能力是否具有普遍性。

## 三、HTTP 错误与前端错误提示

之前前端只要请求失败，就统一显示“连接后端失败”。但实际可能有两种不同情况：

```text
情况一：FastAPI 没有运行
→ 浏览器无法建立连接
→ 提示“无法连接后端”

情况二：FastAPI 正常，但 DeepSeek 超时或不可用
→ 后端返回 HTTP 503
→ 提示“AI 教练暂时无法响应”
```

前端现在会先读取后端响应中的 `detail`。如果服务器成功返回错误响应，就展示后端提供的安全信息；如果网络完全不通，`fetch` 会抛出 `TypeError`，前端才显示无法连接后端。

`503 Service Unavailable` 表示服务暂时不可用。它不是“网页地址不存在”，也不代表用户输入一定错误，而是服务器暂时无法完成这次处理。

## 四、什么是自动化测试

手动测试是打开网页、填写内容、点击按钮，再观察结果。自动化测试则是编写程序，让计算机自动完成输入、调用和结果判断。

今天创建了 `backend/test_main.py`，并运行：

```powershell
backend\.venv\Scripts\python.exe -m unittest discover -s backend -p "test_*.py" -v
```

5 项测试全部通过：

1. `GET /` 返回状态码 200 和正确消息。
2. `/api/debug` 在模型成功时返回提示等级、提示内容和模式。
3. AI 服务故障时返回 503，并且不泄露内部异常。
4. 空代码被 Pydantic 拒绝，返回 422。
5. 超出 1～5 范围的提示等级被拒绝，返回 422。

自动化测试的价值是：以后修改代码后，可以在几秒钟内重新检查旧功能是否被意外破坏。这种检查叫回归测试。

## 五、TestClient、断言与测试用例

`TestClient` 可以在 Python 内部模拟客户端访问 FastAPI，不需要真的打开浏览器。

测试代码会发送类似这样的请求：

```python
response = client.post(
    "/api/debug",
    json={
        "code": "print(1)",
        "expected_result": "输出1",
        "error_message": "",
        "hint_level": 2,
    },
)
```

然后使用断言检查结果：

```python
self.assertEqual(response.status_code, 200)
```

断言的含义是：“我预期这个条件必须成立。”如果实际结果与预期不同，测试就失败，并指出失败位置。

一个独立检查场景叫作测试用例。例如“空代码应该返回 422”就是一个测试用例。

## 六、Mock 和 Patch

如果自动化测试每次都调用真实 DeepSeek，会产生几个问题：

- 消耗 API 额度
- 依赖网络
- 模型回答每次可能不同
- DeepSeek 暂时不可用时测试也会失败

因此测试使用 Mock，也就是模拟对象或替身。

```text
正式运行：FastAPI → generate_debug_hint → DeepSeek
测试运行：FastAPI → generate_debug_hint 的替身 → 固定测试结果
```

`patch()` 会在测试期间临时替换 `generate_debug_hint()`。测试结束后，真实函数会自动恢复。

Mock 不是伪造产品功能，而是隔离外部依赖，让测试只检查当前关注的代码是否正确。

## 七、从占位复盘到可填写表单

原来的“本次学习记录”只显示几行占位文字。今天将它改为四个受控输入框：

- 错误类型
- 涉及知识点
- 我的错误原因
- 下次如何避免

输入框的值由 React 状态保存。用户修改输入时，`onChange` 调用相应的 `set...` 函数更新状态。

在用户点击“我找到问题了”之前，输入框和保存按钮处于禁用状态。这样可以让产品流程更明确：先调试，再复盘。

保存时使用：

```javascript
recordFields.some((field) => field.trim() === "")
```

它会检查四项中是否至少有一项为空。如果内容不完整，记录不会保存。

## 八、localStorage 是什么

`localStorage` 是浏览器提供的本地键值存储。数据保存在当前浏览器中，网页刷新或浏览器重启后仍然存在。

BugMentor 使用固定键名：

```javascript
const STORAGE_KEY = "bugmentor-learning-records";
```

保存链路是：

```text
React 中的复盘对象
→ JSON.stringify()
→ JSON 字符串
→ localStorage.setItem()
→ 浏览器本地存储
```

读取链路是：

```text
localStorage.getItem()
→ JSON 字符串
→ JSON.parse()
→ JavaScript 数组
→ React 状态
→ 页面历史卡片
```

`JSON.stringify()` 叫序列化，把 JavaScript 对象转换为可以保存的文本；`JSON.parse()` 叫反序列化，把文本恢复成 JavaScript 数据。

## 九、为什么只保留最近 20 条

保存代码使用：

```javascript
[...learningRecords, newRecord].slice(-20)
```

它先把新记录添加到数组末尾，再截取最后 20 条。

这属于资源边界。虽然 localStorage 有容量限制，但产品仍应主动控制数据规模，避免记录无限增加。

当前学习记录只保存在当前浏览器：

- 不会上传到后端
- 不会同步到 GitHub
- 不会自动跨浏览器或跨设备同步
- 清理浏览器网站数据后可能消失

因此它适合当前 MVP，但不能替代未来的数据库和账号系统。

## 十、历史记录展示与 map

React 使用 `map()` 把记录数组转换成多个卡片：

```text
learningRecords 数组
→ map(record)
→ 每条记录生成一个 record-card
→ React 显示历史列表
```

显示前使用：

```javascript
[...learningRecords].reverse()
```

`...` 创建数组副本，`reverse()` 再将副本倒序，让最新记录排在最前面。这样不会直接修改 React 状态中的原数组。

每个卡片还需要稳定的 `key`，帮助 React 判断列表中的哪一项发生了变化。当前使用保存时间 `savedAt` 作为 key。

## 十一、本地数据也需要验证

虽然数据来自当前浏览器，仍然不能假设它永远正确。用户可能手动修改浏览器存储，旧版本也可能留下不同结构的数据。

`isValidLearningRecord()` 会检查：

- 记录是对象且不是 `null`
- 四项复盘都是字符串
- `savedAt` 是合法日期字符串

读取时只保留验证通过的数据：

```javascript
savedRecords.filter(isValidLearningRecord)
```

这是一种输入校验。系统边界不仅是 HTTP 接口，文件、浏览器存储和第三方 API 返回值同样属于需要验证的外部数据。

React 使用 `{record.errorType}` 等方式渲染文字，会自动进行必要的转义。项目没有使用 `innerHTML`，因此记录只会作为普通文本显示，不会作为网页代码执行。

## 十二、今天认识的专业名词

| 专业名词 | 我的理解 |
|---|---|
| Automated Test | 由程序自动执行输入、调用和结果判断 |
| Test Case | 一个独立的测试场景 |
| Regression Test | 修改代码后检查原有功能是否被破坏 |
| TestClient | 在 Python 中模拟客户端访问 FastAPI |
| Assertion | 声明并检查预期结果必须成立 |
| Mock | 替代真实依赖的模拟对象 |
| Patch | 测试期间临时替换函数或对象 |
| localStorage | 浏览器提供的本地键值存储 |
| Serialization | 把对象转换成可保存文本的过程 |
| Deserialization | 把文本恢复为程序数据的过程 |
| Data Validation | 检查数据类型、结构和范围 |
| map | 把数组中的每个元素转换成页面元素 |
| key | React 列表中标识每个元素的稳定值 |
| HTTP 503 | 服务器暂时无法提供所需服务 |
