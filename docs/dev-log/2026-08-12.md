# BugMentor 开发日志：Day 2

日期：2026-08-12

## 今日目标

回顾昨天的前端开发过程，进一步理解 JavaScript、Node.js、npm、Vite、React、HTML 和 CSS 的作用，以及它们在项目中的关系。

## 今天学习了什么

### 1. HTML：网页的结构与内容

HTML 用来描述网页中有什么，以及各部分内容的层级和含义，例如标题、段落、按钮、表单和主要内容区域。

可以把 HTML 理解为房子的结构和房间用途。它决定页面包含哪些部分，但通常不负责页面的外观和点击后的行为。

### 2. CSS：网页的外观与布局

CSS 用来控制网页的颜色、字体、大小、间距、边框、排列方式、动画和响应式布局。

如果 HTML 是房子的结构，那么 CSS 就像装修和空间设计。它不仅让页面更美观，也决定不同区域如何排列，以及页面在电脑和手机上如何显示。

### 3. JavaScript：网页的行为与逻辑

JavaScript 是一种编程语言，负责网页的交互和业务逻辑，例如：

- 响应按钮点击
- 读取和校验用户输入
- 修改页面内容
- 请求服务器数据
- 保存和更新页面状态

需要纠正的一点是：浏览器中的 JavaScript 不依赖 Node.js 才能运行。Chrome、Edge 等浏览器本身就有 JavaScript 引擎，可以直接执行网页中的 JavaScript。

JavaScript 也不只用于前端，还可以用于后端服务、桌面应用、移动应用和自动化脚本。

### 4. Node.js：浏览器之外的 JavaScript 运行环境

Node.js 不是 JavaScript 的基础，而是 JavaScript 的一种运行环境。

浏览器和 Node.js 都可以运行 JavaScript，但使用场景不同：

- 浏览器中的 JavaScript 主要负责网页内容和交互
- Node.js 中的 JavaScript 可以操作文件、网络服务、数据库和开发工具

在 BugMentor 项目中，Node.js 主要用于运行 npm、Vite 等前端开发工具。项目构建完成后，网页代码仍然主要由用户的浏览器执行。

### 5. npm：项目的软件包管理工具

npm 可以理解为“软件包仓库、安装工具和项目物料清单”的组合。

它能够：

- 安装 React、Vite 等项目依赖
- 记录项目需要哪些软件包
- 管理依赖的版本
- 执行项目中配置好的开发和构建命令

npm 中的软件包不只是现成模板，也包括界面库、开发工具、测试工具、图表工具和网络请求工具等。

### 6. Vite：前端开发与构建工具

Vite 为前端项目提供快速的开发环境，主要负责：

- 创建项目基础结构
- 启动本地开发服务器
- 在代码修改后快速刷新页面
- 处理 JSX、CSS、图片等资源
- 将源代码构建成适合部署的网页文件

Vite 服务于开发和构建过程，不会代替 JavaScript，也不是用户最终看到的网页内容。

### 7. React：构建复杂用户界面的 JavaScript 库

React 的主要作用是帮助开发者组织和管理交互复杂的网页界面。

React 有两个重要概念：

#### 组件

组件可以把一个大页面拆成多个独立、可维护、可重复使用的小模块，例如标题栏、代码输入区、提示卡片和学习记录区域。

#### 状态

状态是页面当前需要记住的数据，例如用户输入的代码、当前提示等级、是否正在加载，以及问题是否已经解决。

当状态改变时，React 会自动更新页面中需要变化的部分。开发者不需要每次都手动查找和修改网页元素。

React 不是一门新的编程语言。React 代码本质上仍然是 JavaScript，其中类似 HTML 的写法叫作 JSX，需要由 Vite 等工具进行处理。

## 它们之间的关系

```text
网页
├── HTML：定义内容和结构
├── CSS：控制外观和布局
└── JavaScript：实现行为和逻辑
    └── React：用组件和状态组织复杂界面
        └── Vite：提供开发服务器和构建能力

Node.js：让 JavaScript 可以在浏览器之外运行
└── npm：安装、记录和管理项目依赖
```

在实际开发 BugMentor 时，完整流程可以理解为：

1. Node.js 在电脑上运行前端开发工具
2. npm 安装和管理 React、Vite 等依赖
3. Vite 启动本地开发环境
4. 使用 React 和 JavaScript 编写页面组件与交互逻辑
5. 使用 JSX 描述页面结构，使用 CSS 设置外观和布局
6. Vite 将项目构建为浏览器能够加载的文件
7. 用户打开网页后，由浏览器执行最终的 JavaScript 代码

## 今日理解纠正

学习前的理解中，有两点需要修正：

1. JavaScript 不需要建立在 Node.js 上才能运行；浏览器可以直接运行 JavaScript，Node.js 只是另一种运行环境。
2. npm 不只是调用 JavaScript 模板的工具，而是负责安装、记录和管理项目所需的各种软件包。

## 今日总结

今天建立了对前端技术栈更完整的认识：HTML 管内容和结构，CSS 管外观和布局，JavaScript 管行为和逻辑；React 帮助组织复杂界面，Vite 提供快速的开发和构建环境，Node.js 让开发工具能够在浏览器之外运行，npm 则负责安装和管理项目依赖。

这次复盘也让我不再只会照着命令运行项目，而是开始理解 BugMentor 项目中的每一种技术为什么存在，以及它们是如何协作的。
